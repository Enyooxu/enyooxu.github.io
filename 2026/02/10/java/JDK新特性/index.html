问题背景今天将一个老项目的JDK从8升级到17以后发现所有的校验全部失效了，属性如下。 1234import javax.validation.constraints.NotNull;@NotNull(message = "authType不能为空")private Integer authType; 问题分析查阅资料以后发现，根本原因是 Java EE（Java Enterprise Edition）整体从 Oracle 转移到了 Eclipse 基金会，并更名为 Jakarta EE。由于 Oracle 拥有 “Java” 商标，Eclipse 基金会不能继续使用 javax.* 包名。因此，从 Jakarta EE 9 开始（2020年发布），所有原 Java EE 的 API 从 javax.* 重命名为 jakarta.*。这种问题最容易出现在升级了JDK17以后。 解决方法修改导包路径即可，其他的校验注解的路径也一样。 1import jakarta.validation.constraints.NotNull;
