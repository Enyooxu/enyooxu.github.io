本质原因是SQL 采用的是三值逻辑。但在 SQL 中，逻辑判断有三种结果： True (真)、False (假)、Unknown (未知)。根据 SQL 标准，任何与 NULL 进行的算术或比较运算，其结果都是 Unknown。

  • 1 = NULL → Unknown
  • NULL = NULL → Unknown（即便两个都是未知，也不代表它们相等）
  • NULL != NULL → Unknown

对于最后的查询来说只会返回逻辑结果为true的数据，所以这里的查询是查不到结果的。造成这个问题的原因是这个数据是一个老数据，在加新字段的没有对老数据做兼容。
